# BirdBot 🐦

Telegram-бот для помощи в пристройстве, поиске и возврате домашних птиц. Бот собирает анкеты от пользователей и отправляет их администраторам для дальнейшей обработки.

## ✨ Возможности

- **Пристройство птицы** — анкета для владельцев, которые хотят пристроить птицу в хорошие руки
- **Поиск птицы** — анкета для тех, кто хочет взять птицу из приюта или пристроить
- **Потерялась птица** — форма для поиска потерянных птиц
- **Нашлась птица** — форма для тех, кто нашел птицу

### Особенности

- 📸 Поддержка до 5 фотографий в каждой анкете
- 📱 Валидация и сбор контактных данных (телефон, Telegram)
- 🔒 Контакты отправляются отдельным сообщением для защиты приватности
- ⏭️ Опциональные поля с возможностью пропуска
- 🎯 Гибкая система форм с валидацией данных

## 🚀 Быстрый старт

### Требования

- Python 3.11+
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))
- ID админского чата/канала

### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/BirdBot.git
cd BirdBot
```

2. Создайте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Настройте переменные окружения:
```bash
cp env.example .env
```

Отредактируйте `.env` файл:
```env
BOT_TOKEN=your_bot_token_here
ADMIN_CHAT_ID=your_admin_chat_id
CARE_ADMIN_CONTACT=@admin_username  # опционально
```

5. Запустите бота:
```bash
python bot.py
```

## 🐳 Docker

### Использование Docker Compose

1. Создайте `.env` файл (см. выше)

2. Запустите контейнер:
```bash
docker-compose up -d
```

3. Просмотр логов:
```bash
docker-compose logs -f birdbot
```

4. Остановка:
```bash
docker-compose down
```

### Использование Docker

```bash
docker build -t birdbot .
docker run -d --name birdbot --env-file .env birdbot
```

## ⚙️ Конфигурация

### Переменные окружения

| Переменная | Описание | Обязательная |
|-----------|----------|--------------|
| `BOT_TOKEN` | Токен бота от BotFather | ✅ Да |
| `ADMIN_CHAT_ID` | ID чата/канала для получения анкет | ✅ Да |
| `CARE_ADMIN_CONTACT` | Контакт администратора для передержки | ❌ Нет |

### Как получить ID чата/канала

1. Добавьте бота [@userinfobot](https://t.me/userinfobot) в ваш чат/канал
2. Отправьте любое сообщение
3. Бот покажет ID чата

Или используйте [@getidsbot](https://t.me/getidsbot)

## 📝 Типы анкет

### 1. Пристройство птицы (Owner Form)
- Город
- Вид птицы
- Причина пристройства
- Обследования и анализы
- Фотографии (до 5)
- Пожелания к новому дому
- Контакты

### 2. Поиск птицы (Seeker Form)
- Город
- Возраст
- Работа/учеба
- Жилье (собственное/аренда)
- Другие животные/дети
- Опыт с птицами
- Опыт содержания
- Фотографии условий содержания (до 5)
- Ссылка на конкретный пост (опционально)
- Контакты

### 3. Потерялась птица (Lost Form)
- Город
- Вид птицы
- Дата и время потери
- Адрес
- Фотографии (до 5)
- Контакты

### 4. Нашлась птица (Found Form)
- Город
- Вид птицы
- Дата и время находки
- Адрес
- Нужна ли передержка (Да/Нет)
- Фотографии (до 5)
- Контакты

## 🔐 Безопасность

- Контакты пользователей отправляются **отдельным сообщением** от анкеты
- Это позволяет пересылать анкеты в другие чаты без раскрытия контактов
- Все данные хранятся только в памяти бота (FSM) и не сохраняются в базе данных

## 🛠️ Разработка

### Зависимости

- `aiogram==3.10.0` — асинхронный фреймворк для Telegram Bot API
- `aiohttp>=3.9` — HTTP клиент/сервер
- `pydantic-settings>=2.4` — управление настройками

### Добавление новой формы

1. Создайте новый файл в `handlers/` (например, `new_form.py`)
2. Определите StatesGroup с состояниями формы
3. Создайте обработчики для каждого состояния
4. Добавьте шаблон в `messaging.py` (FORM_TEMPLATES и FORM_TITLES)
5. Зарегистрируйте роутер в `bot.py`
